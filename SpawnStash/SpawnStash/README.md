# SpawnStash 2.0

Paper 1.21.4 / Java 21.

## Auswahl und Speichern

1. Nutze einen **Arrow of Oozing** oder `/stash wand`.
2. Rechtsklick auf Block 1 = erste Ecke.
3. Rechtsklick auf Block 2 = zweite Ecke.
4. `/stash save <name>` speichert den kompletten Bereich inklusive Luft und Container-Inhalten.
5. `/spawnstash <name>` fügt die Vorlage so ein, dass der beim Speichern verwendete Anker an deiner aktuellen Position liegt.

Weitere Befehle:
- `/stash list`
- `/stash delete <name>`
- `/stash clear`
- `/stash reload`

Rechte:
- `spawnstash.use`
- `spawnstash.edit`
